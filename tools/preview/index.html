Dev harness — not part of the product package. The frame loads the shipped theme layers (wavira/assets/css/{tokens,base,components,utilities}.css), the shipped player stylesheet (wavira-core/assets/css/player.css) and the shipped scripts (wavira/assets/js/index.js, wavira-core/assets/js/index.js). The player's WordPress REST routes are stubbed with in-memory demo data and generated tones, so no network and no server are involved. Media queries respond to the frame width because the frame is a real viewport.
