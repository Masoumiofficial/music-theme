# BRAND-RESEARCH.md — Autonomous Brand Naming Engine

**Project:** Legacy Music WordPress Theme → new commercial WordPress music-publishing product
**Phase:** 0 — Brand Lock (pre-development)
**Date of research:** 2026-10-05
**Researcher:** Arena Agent (autonomous; no user input requested or used)

> **Method note.** All screening below is *preliminary*. Search engines cannot prove non-use anywhere in
> the world, so this document never claims a name is "unused". Statements are scoped to
> "no significant direct conflict was identified in the sources searched".
> Nothing in this file is legal clearance.
> **Preliminary screening only — professional trademark clearance is still recommended.**

---

## 1. Constraints applied

Naming had to satisfy, simultaneously:

| Constraint | Requirement |
| --- | --- |
| Product | Premium WordPress **music publishing ecosystem** (theme + core plugin + player + docs) |
| Market | Iran (RTL-first) **and** international (LTR), Persian/Arabic/English pronunciation |
| Length | Short, syllable-friendly, no ambiguous spelling |
| Extensibility | Must work as Theme, Plugin, REST namespace, SaaS/product family, mobile app, logo |
| Legality | No known music brand, WordPress product, marketplace item, or heavyweight trademark collision |
| Domain | `.com` preferred; a paid-for-sale `.com` counted as a conflict, not availability |
| Anti-generic | Bare `Music/Audio/Sound/Beat/Tune/Melody/Player/…Press` words excluded by rule |

being the generic bare word "Wave") and immediately out-scored every round-1 candidate on
domain signal, pronunciation and logo potential.

## 4. Domain signal (DNS, 2026-10-05)

DNS **cannot** prove availability and a resolving domain can be a parked page. It is used only as a
*risk band*. Method: `getaddrinfo` A/AAAA lookup. A wildcard control was run first
(`zzqxvbnm1234asdf.com`, `qwertyuiop9876543zz.com`, `thisdomaindoesnotexist9x8y7z.com`) — all three
returned NXDOMAIN, so the resolver was **not** hijacking/wildcarding; results below are meaningful
as a signal. Registrar-level WHOIS verification is still required before purchase.

## 8. Sources consulted (this study)

- Web search (exact and variant queries) for each finalist, including `NAME music`,
  `NAME WordPress`, `NAME theme`, `NAME plugin`, `NAME app`, `NAME GitHub`, `NAME trademark`.
- `wordpress.org/themes` search for the finalists.
- Envato/ThemeForest/CodeCanyon appearance check (found the Cadenza theme; none for Wavira/Lyrisma/Klangra).
- GitHub topic/repo search (no repos named Wavira/Lyrisma found).
- Domain DNS resolution + wildcard control (see §4).
- Adjacent-name discovery (Lyria, Lyrion, Lyrist, Ostinato, Soniva entities, Sonance/Sonar class).
- Trademark databases were **not** queried directly (USPTO/TMview pages are search-intermediated);
  the trademark line below is therefore weaker than the rest of this study.
