# واویرا (Wavira) — سامانهٔ انتشار موسیقی برای وردپرس

> **وضعیت: نسخهٔ ۰.۱۱.۰ — نامزد انتشار.** همهٔ ویژگی‌های نسخهٔ ۱ به‌همراه ابزار مهاجرت از قالب قدیمی
> و بستهٔ نصب آماده است: مدل داده، API اختصاصی، موتور پخش‌کننده، قالب‌ها و بلوک‌ها، صفحهٔ هنرمند، بخش
> اخبار، همکاری با افزونه‌های سئو، بودجهٔ کارایی و **بومی‌سازی فارسی**: ترجمهٔ هر دو بسته، تقویم جلالی
> (شمسی) با ارقام فارسی، پیش‌فرض‌های ایرانی، محتوای نمایشی فارسی و فونت وزیرمتن در خود بسته. آنچه
> مانده «کارهای انتشار» است — فهرست مورد‌به‌مورد در `docs/RELEASE-CANDIDATE.md` §۶.

**واویرا** یک محصول وردپرسی برای **انتشار و کشف موسیقی** است: هنرمند، آلبوم، قطعه، ویدیوی موسیقی،
سبک، متن ترانه، دانلود چندکیفی و یک پخش‌کنندهٔ درجه‌یک — راست‌به‌چپ در اصل و با پشتیبانی کامل
چپ‌به‌راست، حالت روشن و تاریک، سازگار با گوتنبرگ، ساخته‌شده برای کارایی و دسترس‌پذیری WCAG 2.2 AA.

**طراح و نویسنده: اتحاد وردپرس — [etehadwp.com](https://etehadwp.com/)**

## این نسخه چه چیزهایی را فارسی می‌کند

| بخش | توضیح |
| --- | --- |
| رابط کاربری، پیشخوان و ویرایشگر بلوک | ترجمهٔ کامل در هر دو بسته (`fa_IR.po` و `fa_IR.mo`) — در مخزن، آمادهٔ استفاده |
| تاریخ‌ها | **تقویم جلالی (شمسی)** روی سایت‌های `fa_IR`: «۱۳ مهر ۱۴۰۵» با ارقام فارسی، در کارت‌های خبر، صفحهٔ هنرمند، آرشیوها و صفحهٔ ترانه |
| ارقام | همهٔ اعداد قابل‌مشاهده (مدت قطعه، کیفیت دانلود، حجم فایل، شمارش‌ها، شمارهٔ قطعه‌ها) با ارقام فارسی |
| محتوای نمایشی | `wp wavira seed` یک سایت موسیقی فارسی می‌سازد: هنرمند (آرمان راد)، آلبوم (شب‌های تهران)، تک‌آهنگ (باران بهاری)، چهار قطعه با متن ترانهٔ تولیدشده، سه سبک و یک ویدیو |
| پیش‌فرض‌های سایت | `fa_IR`، منطقهٔ زمانی `Asia/Tehran`، آغاز هفته از **شنبه**، قالب تاریخ `j F Y` و ساعت ۲۴ساعته |
| فهرست اصلی | ساخت خودکار منوی «خانه، آهنگ‌ها، آلبوم‌ها، هنرمندان، ویدیوها، سبک‌ها» و اتصال آن به جایگاه `primary` قالب |
| کارگاه پیش‌نمایش توسعه | `node tools/preview/serve.mjs` یک صفحهٔ فارسی (`dir="rtl"`, `lang="fa-IR"`) با تاریخ‌های جلالی و رشته‌های فارسی پخش‌کننده نشان می‌دهد |

راهنمای کامل بهره‌برداری: [`docs/PERSIAN-LOCALIZATION.md`](../PERSIAN-LOCALIZATION.md)
(انگلیسی، برای تیم فنی). تصمیم‌های معماری: [ADR 0017](../adr/0017-jalali-dates-and-iranian-defaults.md)
و [ADR 0015](../adr/0015-persian-first-localisation.md).

## چه چیزی عمداً انگلیسی یا میلادی می‌ماند

| بخش | دلیل |
| --- | --- |
| `<time datetime>`، `datePublished` در داده‌های ساختاریافته، نقشهٔ سایت، خوراک‌ها | استاندارد ماشین‌خوان؛ تاریخ جلالی در این جای‌ها نامعتبر است (و برای سئو زیان‌آور) |
| پاسخ‌های REST و پیشخوان | ابزارها و افزونه‌ها تاریخ ISO را مقایسه می‌کنند؛ نمایش پیشخوان میلادی می‌ماند |
| کد، نام فایل‌ها، اسلاگ‌ها، شناسه‌ها | خوانایی و پایداری فنی؛ اسلاگ فارسی از طریق فیلتر `wavira_rewrite_slugs` قابل تغییر است |
| متن‌های فارسی داخل کد (تقویم، محتوای نمایشی) | دادهٔ محتوا و تقویم‌اند، نه رشتهٔ رابط؛ بنابراین وارد فایل ترجمه نمی‌شوند |

## اجرای سریع دموی فارسی

```bash
wp wavira seed                 # محتوای فارسی + پیش‌فرض‌های ایرانی
wp wavira seed --english       # نسخهٔ انگلیسی (برای توسعه)، بدون تغییر تنظیمات سایت
wp wavira seed --no-site       # فقط محتوا؛ بدون تغییر تنظیمات و منو

wp wavira migrate --detect      # سایت قدیمی چه چیزهایی دارد؟ (فقط خواندن)
wp wavira migrate --dry-run     # نقشهٔ کامل مهاجرت، بدون هیچ نوشتنی
wp wavira migrate               # اجرای مهاجرت (قابل تکرار، قابل ادامه، قابل بازگردانی)
wp wavira migrate --rollback    # بازگردانی به وضعیت قبلی
```

مهاجرت از قالب قدیمی (فاز ۰.۱۱.۰) در `wavira-core/src/Migration/` است و فقط از طریق WP-CLI اجرا می‌شود:
هیچ بخشی از آن در مسیر بارگذاری معمولی سایت نیست. هر مقدار قدیمی پیش از تغییر در
`_migration_backup` و `_migration_raw` نگه داشته می‌شود، هیچ پستی حذف یا منتشر/لغو‌منتشر نمی‌شود، و
هر چیزی که قابل حدس‌زدن نباشد (نام هنرمند بی‌مرجع، تصویر غیرمحلی، نوع ناشناخته) در فهرست
«نیازمند بازبینی» گزارش می‌شود. جزئیات: `docs/MIGRATION-BLUEPRINT.md` §۸ و ADR 0018.

## بستهٔ نصب و فونت

```bash
node tools/build.mjs && node tools/package.mjs          # ساخت سه بسته در dist/
node tools/package.mjs --check                           # دروازهٔ [PACKAGE]
node tools/package.mjs --check --strict                  # افزون بر آن، فایل‌های مخصوص فروشگاه
```

سه فایل ساخته می‌شود: `wavira-theme-0.11.0.zip`، `wavira-core-0.11.0.zip` و
`wavira-0.11.0-bundle.zip` (هر دو بسته + پوشهٔ `README-FIRST/` شامل راهنمای فارسی نصب و کاربرد و
پروانه‌ها). بسته‌ها قطعی (deterministic) هستند: دو بار ساخت یک نسخه، بایت‌به‌بایت یکسان است.

فونت **وزیرمتن ۳۳.۰۰۳** بدون تغییر در قالب عرضه می‌شود
(`wavira/assets/fonts/vazirmatn/vazirmatn-variable.woff2`، یک فایل متغیر برای وزن‌های ۱۰۰ تا ۹۰۰)،
در `theme.json` به‌صورت `fontFace` اعلام می‌شود و در `wp_head` پیش‌بارگذاری (preload) می‌شود؛ متن
پروانهٔ OFL نیز کنارش قرار دارد. هیچ فونتی از سرور بیرونی بارگذاری نمی‌شود.
